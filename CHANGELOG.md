# Change Log

## [0.6.5]

- Fix encoding error in communciation between LSP client and server.

## [0.6.0]

- Add setting for font size in webview.
- Update autoclosing pairs to match squirrel's syntax.

## [0.5.0]

- Explained in more detail possible errors on extension's startup.
- Implement highlighting of `admit` and `Abort` commands.

- Fix syntax highlighting, now correctly colors identifiers starting with a capital letters as identifiers.
- Fix undo issue when deleting dots in a processed proof.

## [0.1.0]

- Add support for proof processing via squirrel's interactive mode.
- Add syntaxic highlighting for squirrel's files.
